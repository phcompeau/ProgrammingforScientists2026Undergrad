You learn the basics of programming on your own time, from the readings and code-along videos at programmingforlovers.com. We use class to build the scientific applications together. Each day below lists what to finish beforehand, and class starts from the assumption that you finished it.

Course code on GitHub

Everything we write together in class lives in github.com/phcompeau/ProgrammingforScientists2026Undergrad, together with the starter files for every assignment. Clone it in the first week and pull from it before each class, because we add to it every week.

git clone https://github.com/phcompeau/ProgrammingforScientists2026Undergrad.git

New to Git? GitHub Desktop does the same thing with buttons: File > Clone Repository > URL, then Fetch origin and Pull each week. The repository README explains how Starter Code and Finished Code are organized, and how to keep your own edits out of Git's way.

Final project

You will spend the second half of the semester building a piece of scientific software of your own with Claude Code. The proposal is due Wednesday, October 7, so that you get feedback before Fall Break. Every project date is also on the calendar below. Read the project description (PDF).

  • Watch me build one, slowly. These two Vibe Coding Studio videos rebuild the spatial games model from our September 22 class, slowly and completely, starting from the Nowak and May paper. Watch the end of Session 3, from 1:17:30 (47 minutes), which sets up the project folder in Claude Code and gives Claude a memory, the paper, and skills, then writes and tests the first function. Then watch all of Session 4, (2 hours 16 minutes), which writes a spec, builds and tests the model, animates it, and deploys it to the web as a finished app. That is the same path your project will follow. I went slowly and steadily on purpose so that you can see every step; with Opus 5.5, Claude will build something much bigger than this with less prompting and more accuracy.
  • Claude accounts. We are going to get a Claude account for every student who does not already have one. If you do not have one yet, hold off on buying one and stand by for details.
  • How I set up Claude. My high-level guide to the setup I use every day, and which parts of it matter for your project.
