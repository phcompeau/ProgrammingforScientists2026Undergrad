How this course works

This course flips the basics. You learn programming fundamentals outside of class using the readings and code-along videos at programmingforlovers.com, and we spend class time building the fun scientific applications together: hunting for replication origins, forecasting elections, growing cellular automata, simulating gravity, and more. Class assumes you have completed the preparation listed for that day.

How to prepare

Each code-along length below is watch time. Do not just watch: pause and type the code yourself, and complete the exercises on each page. Budget roughly twice the video length. Code-along exercises are submitted in the homework autograder course and count toward your programming grade, and daily challenges continue throughout the semester.
