Set Up Your Build Journal

Do this once, in your project repository. It takes about a minute. If you already set it up before October 31, do it once more to get the readable journal and Codex support.

For you

Open Claude Code (or Codex) in your project folder and paste this:

Follow the setup instructions at https://phcompeau.github.io/ProgrammingforScientists2026Undergrad/project/journal/setup.txt for my 02-120 build journal, then tell me what you did.

After that, every Claude Code and Codex session in this folder is copied into a journal/ folder automatically, including the sessions you had before you set this up, and again every time you commit. All you have to do is commit and push regularly. We collect your repository at 11:59 pm on each checkpoint date: October 30, November 10, November 20, and December 1.

Reading your journal. The raw logs in journal/ are JSON, which is hard to read. A readable copy of every session (your prompts, the AI's replies, and a one-line note for each action it took) is written to journal/readable/. Open any file there on GitHub and it displays as a normal page. This is also what a classmate or TA reads when they review your work.

Claude Code or Codex both work, in a terminal or in the VS Code extension. Either one records its sessions on your computer, and the journal picks them up.

If you work in a chat app

Chats in ChatGPT (the website or app) or in the Claude app run in the cloud, so nothing from them reaches your journal on its own. They still count, but you have to share them yourself:

  1. At the end of every chat session about your project, click Share and copy the link. A share link shows the chat only up to the moment you create it, so if you come back to the same chat later, share it again and update the link.
  2. Add one line per chat to journal/chat_links.md in your repository: the date, the link, and one sentence about what you worked on. For example: 2026-11-02 | https://chatgpt.com/share/... | Fixed the diffusion step in my Gillespie simulation
  3. Commit and push. Before each checkpoint, check that every project chat is on the list with an up-to-date link. A chat that is not on the list by the checkpoint does not count.

Chats you had before October 31 count too: share them and add them to the list before checkpoint 2 (November 10). Going forward, we recommend building in Claude Code or Codex inside your project folder, since that is logged for you.

If something goes wrong

If the AI says a step was denied or blocked, your permission mode is refusing the setup commands (auto mode in Claude Code does this). Press Shift+Tab until the mode reads "accept edits" or the default "ask" mode (in VS Code, click the mode name under the prompt box), then type continue and approve each step when asked. Once setup is done, you can switch back.

If the push fails because GitHub asks for a username (or "this computer has no saved GitHub login"), your setup is committed but this computer is not signed in to GitHub yet. The easiest fix is the GitHub CLI: install it from cli.github.com (on a Mac with Homebrew, brew install gh), then run gh auth login, choose GitHub.com, HTTPS, and "Login with a web browser", and finally run gh auth setup-git. Then push again (or ask your AI to). In VS Code, clicking Sync Changes in the Source Control panel and signing in when it asks also works.

On Windows, if typing claude says it is not recognized right after you install it, the installer's folder is not on your PATH yet. In PowerShell, run [Environment]::SetEnvironmentVariable("Path", $env:Path + ";$env:USERPROFILE\.local\bin", "User"), then close and reopen the terminal.

If you have not already, submit your repository link on Canvas (Project Repository Link) and add GitHub user phcompeau as a collaborator if your repository is private.

Privacy. Your journal holds only the sessions from this project folder, never your other folders or your personal memory and skills. Read through journal/readable/ before you push if you are worried, and never paste a password or API key into your AI tool. Only course staff, and classmates you choose to show it to in recitation, read your journal.
