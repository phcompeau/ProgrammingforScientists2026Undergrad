Set Up Your Build Journal

Do this once, in your project repository. It takes about a minute. If you already set it up before October 31, do it once more to get the readable journal and Codex support.

For you

Open Claude Code (or Codex) in your project folder and paste this:

Follow the setup instructions at https://phcompeau.github.io/ProgrammingforScientists2026Undergrad/project/journal/ for my 02-120 build journal, then tell me what you did.

After that, every Claude Code and Codex session in this folder is copied into a journal/ folder automatically, including the sessions you had before you set this up, and again every time you commit. All you have to do is commit and push regularly. We collect your repository at 11:59 pm on each checkpoint date: October 30, November 10, November 20, and December 1.

Reading your journal. The raw logs in journal/ are JSON, which is hard to read. A readable copy of every session (your prompts, the AI's replies, and a one-line note for each action it took) is written to journal/readable/. Open any file there on GitHub and it displays as a normal page. This is also what a classmate or TA reads when they review your work.

Claude Code or Codex both work, in a terminal or in the VS Code extension. Either one records its sessions on your computer, and the journal picks them up.

If you work in a chat app

Chats in ChatGPT (the website or app) or in the Claude app run in the cloud, so nothing from them reaches your journal on its own. They still count, but you have to share them yourself:

  1. At the end of every chat session about your project, click Share and copy the link. A share link shows the chat only up to the moment you create it, so if you come back to the same chat later, share it again and update the link.
  2. Add one line per chat to journal/chat_links.md in your repository: the date, the link, and one sentence about what you worked on. For example: 2026-11-02 | https://chatgpt.com/share/... | Fixed the diffusion step in my Gillespie simulation
  3. Commit and push. Before each checkpoint, check that every project chat is on the list with an up-to-date link. A chat that is not on the list by the checkpoint does not count.

Chats you had before October 31 count too: share them and add them to the list before checkpoint 2 (November 10). Going forward, we recommend building in Claude Code or Codex inside your project folder, since that is logged for you.

If something goes wrong

If the AI says a step was denied or blocked, your permission mode is refusing the setup commands (auto mode in Claude Code does this). Press Shift+Tab until the mode reads "accept edits" or the default "ask" mode (in VS Code, click the mode name under the prompt box), then type continue and approve each step when asked. Once setup is done, you can switch back.

If the push fails because GitHub asks for a username (or "this computer has no saved GitHub login"), your setup is committed but this computer is not signed in to GitHub yet. The easiest fix is the GitHub CLI: install it from cli.github.com (on a Mac with Homebrew, brew install gh), then run gh auth login, choose GitHub.com, HTTPS, and "Login with a web browser", and finally run gh auth setup-git. Then push again (or ask your AI to). In VS Code, clicking Sync Changes in the Source Control panel and signing in when it asks also works.

On Windows, if typing claude says it is not recognized right after you install it, the installer's folder is not on your PATH yet. In PowerShell, run [Environment]::SetEnvironmentVariable("Path", $env:Path + ";$env:USERPROFILE\.local\bin", "User"), then close and reopen the terminal.

If you have not already, submit your repository link on Canvas (Project Repository Link) and add GitHub user phcompeau as a collaborator if your repository is private.

Privacy. Your journal holds only the sessions from this project folder, never your other folders or your personal memory and skills. Read through journal/readable/ before you push if you are worried, and never paste a password or API key into your AI tool. Only course staff, and classmates you choose to show it to in recitation, read your journal.

Instructions for your AI (you can skip this)

Students: you do not need to read or follow this section. It is written for Claude Code or Codex, which reads this page when you paste the prompt above, so "the student" below means you.

AI: you are setting up a student's build journal for the 02-120 final project. Work in the root of the student's project repository (the folder where you are running).

  1. First check that you are Claude Code or Codex running on the student's own computer, in a terminal or the VS Code extension, inside their project repository. If you are a chat in the Claude app, ChatGPT, or Cowork, or you cannot see the repository's files on the student's computer, stop: tell the student that the journal only records Claude Code and Codex sessions, that they should open a terminal in their project folder, start claude or codex, and paste the setup prompt there, and that chat work is shared by link as described in "If you work in a chat app" on this page.
  2. If any step below is denied by your permission mode (for example, auto mode), do not work around it. Stop and tell the student: "Your permission mode blocked this step. Press Shift+Tab to switch to accept-edits or the default ask mode (in VS Code, click the mode name under the prompt box), type continue, and approve each step." Then pick up where you left off.
  3. Download save_journal.py from https://phcompeau.github.io/ProgrammingforScientists2026Undergrad/project/journal/save_journal.py and save it, unchanged, as .claude/hooks/save_journal.py (use this path even if you are Codex). If the file already exists, replace it with this version.
  4. If you are Claude Code: add the hooks in settings.json (https://phcompeau.github.io/ProgrammingforScientists2026Undergrad/project/journal/settings.json) to the project's .claude/settings.json. If that file already exists, merge the SessionStart and SessionEnd entries into it without removing anything already there, and do not add them twice. Use .claude/settings.json, not settings.local.json, so that the hooks are committed with the repository. If you are Codex, skip this step.
  5. Download pre-commit from https://phcompeau.github.io/ProgrammingforScientists2026Undergrad/project/journal/pre-commit and save it, unchanged, as .git/hooks/pre-commit. If a pre-commit hook already exists there and is not this one, show it to the student and ask before replacing it. On macOS or Linux, make it executable with chmod +x .git/hooks/pre-commit.
  6. Run the script once by hand from the project root (python3 .claude/hooks/save_journal.py, or python on Windows) and confirm that journal/ now contains session logs (Codex sessions go in journal/codex/) and that journal/readable/ contains one readable .md file per session.
  7. Make sure that neither journal/ nor .claude/ is listed in .gitignore.
  8. The script replaces common API key and token formats with [REDACTED] automatically, but not passwords or unusual keys. Search the files in journal/ (the raw logs too, not only journal/readable/) for anything that looks like a password, API key, or token. If you find one, tell the student and help them remove it before committing, and tell them to change that password or key, since it was exposed to the AI.
  9. Commit .claude/hooks/save_journal.py, .claude/settings.json (if you changed it), and journal/ with the message Set up build journal, and push. If the push fails because this computer has no saved GitHub login, do not try to work around it: tell the student to follow "If the push fails" on this page, and push again once they are signed in.
  10. Tell the student what you did, show them journal/readable/, and remind them to submit their repository link on Canvas and to commit and push regularly. If they also use ChatGPT or the Claude app for this project, remind them to keep journal/chat_links.md up to date.
