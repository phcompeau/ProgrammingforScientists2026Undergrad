Set Up Your Build Journal

Do this once, in your project repository. It takes about a minute.

For you

Open Claude Code in your project folder and paste this:

Follow the setup instructions at https://phcompeau.github.io/ProgrammingforScientists2026Undergrad/project/journal/ for my 02-120 build journal, then tell me what you did.

After that, every Claude Code session in this folder is copied into a journal/ folder automatically, including the sessions you had before you set this up. All you have to do is commit and push regularly. We collect your repository at 11:59 pm on each checkpoint date: October 30, November 10, November 20, and December 1.

Then, by Friday, October 30, submit your repository link on Canvas (Project Repository Link) and add GitHub user phcompeau as a collaborator if your repository is private.

Privacy. Your journal holds only the sessions from this project folder, never your other folders or your personal memory and skills. Read through journal/ before you push if you are worried, and never paste a password or API key into Claude Code. Only course staff read your journal.

For Claude

You are setting up a student's build journal for the 02-120 final project. Work in the root of the student's project repository (the folder where Claude Code is running).

  1. Download save_journal.py from https://phcompeau.github.io/ProgrammingforScientists2026Undergrad/project/journal/save_journal.py and save it, unchanged, as .claude/hooks/save_journal.py.
  2. Add the hooks in settings.json (https://phcompeau.github.io/ProgrammingforScientists2026Undergrad/project/journal/settings.json) to the project's .claude/settings.json. If that file already exists, merge the SessionStart and SessionEnd entries into it without removing anything already there. Use .claude/settings.json, not settings.local.json, so that the hooks are committed with the repository.
  3. Run the script once by hand from the project root (python3 .claude/hooks/save_journal.py, or python on Windows) and confirm that journal/ now contains one or more .jsonl files.
  4. Make sure that neither journal/ nor .claude/ is listed in .gitignore.
  5. Check the journal files for anything that looks like a password, API key, or token. If you find one, tell the student and help them redact it before committing.
  6. Commit .claude/hooks/save_journal.py, .claude/settings.json, and journal/ with the message Set up build journal, and push.
  7. Tell the student what you did, and remind them to submit their repository link on Canvas by October 30 and to commit and push regularly.
